# UTPLiteApp · Experiencia colaborativa en Android

## Propósito e implementación

Prototipo académico Android que explora la consulta de información estudiantil mediante pantallas de calendario, anuncios, cursos y acceso. El proyecto utiliza **Kotlin, Java y layouts XML**.

## Mi contribución

Los siguientes cambios están vinculados a mi cuenta de GitHub y muestran aportes concretos:

- [Calendario: modelos, adaptadores y pantallas](https://github.com/sromansilva/UTPLiteApp/commit/d2b4dc3).
- [Anuncios y componentes de interfaz](https://github.com/sromansilva/UTPLiteApp/commit/f7095a5).
- [Pantalla de login](https://github.com/sromansilva/UTPLiteApp/commit/3f2478d).

Se trata de un desarrollo en equipo. Estos cambios no implican que toda la aplicación o su diseño sean de mi autoría.

## Estado y limitaciones

La aplicación se presenta como un prototipo, con datos estáticos y acceso de demostración. No se describe como un sistema conectado a los servicios institucionales reales.

Algunas pantallas o acciones son demostrativas o están pendientes, incluidas partes de las descargas y la recuperación de acceso. La revisión del código no acredita compilación, instalación ni funcionamiento completo en dispositivos.
